# Ohana FC 27

A browser football game inspired by Ultimate Team: every player has a unique card with stats and a special power.

**Play it:** https://shayo17.github.io/Agentic-Programming-Lab1/

## Modes
- **Kick-Off**: play vs the computer (5 difficulty levels) or 2 players on one keyboard.
- **Ultimate Team Career**: start with a bronze squad in Division 10, win matches for coins, complete missions, open packs, buy players on the transfer market, and climb to Division 1.

## Controls (vs Computer)
| Action | Key |
|---|---|
| Move | Arrow keys |
| Pass | S |
| Shoot (hold for power) | D |
| Defend / tackle | A |
| Switch player | Q |
| Sprint | Shift |
| Special power | E |

2 Players: Player 1 uses W A S D + C pass, V shoot, X defend, Q switch, Left Shift sprint, E special. Player 2 uses the arrows + K pass, L shoot, J defend, U switch, Right Shift sprint, I special. Gamepads work too. Press H in a match to show the controls, Esc to pause.

All players and clubs are fictional. Plain HTML/CSS/JS, no build step; progress is saved in the browser.
